# Reference

`shade-ledger-prototype.htm` is the single-file demo Dravya IQ grows from. Open it in a browser to see the intended journey, copy and look. It keeps its data in browser storage and runs React through a CDN, so it needs internet.

It is a reference, not a source. Do not copy its structure: it computes in components and stores state in the browser, which this repo's constitution forbids. Where it differs from `specs/contracts/`, the contracts win.

The `.htm` extension keeps the repository gate from reading its JSX style objects as unfilled template placeholders.
