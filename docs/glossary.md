# Glossary

Plain meanings of the shop-floor words used in this repo. Written for the builder, not the chemist.

| Word | Meaning |
| --- | --- |
| Masterbatch | Plastic pellets packed with colour or additive. A customer mixes a small amount into plain plastic to colour their pipe, film or bottle. |
| Carrier | The plain plastic the colour is carried in (LLDPE, PP). It is whatever is left of the recipe after the pigments and additives. |
| Pigment | The colour powder, e.g. Pigment Blue 15:3, carbon black, titanium dioxide (white). |
| Lot | One delivery of one material from a supplier, with its own number. The unit of traceability. |
| Inward register | The book where the storekeeper writes every delivery that arrives. |
| CoA | Certificate of analysis. The supplier's test sheet for a lot, or the certificate the plant gives its own customer for a batch. |
| Lab dip | The lab trial where the chemist matches a customer's colour and fixes the recipe. |
| Shade code | The plant's id for one approved colour recipe, e.g. WS-4471 Ocean Blue. |
| Let-down ratio | How much masterbatch the customer mixes in. 1:40 means 1 part masterbatch to 40 parts plastic, about 2.5%. |
| ΔE (delta E) | One number for how far a colour is from the standard. Below 1.0 the eye barely sees a difference. |
| Batch | One run on the extruder making one shade from specific lots. |
| Batch log | The operator's sheet: which lots and how many kg went in, how much good output came out. |
| Purge | Material lost while starting up or changing colour on the extruder. Normal is a few percent. |
| Mass balance | Kilograms in must equal kilograms out plus purge. A gap means a weighing or writing error, or material leaving untracked. |
| QC register | The quality check book: ΔE, MFI, dispersion, moisture, pass or fail per batch. |
| MFI | Melt flow index. How easily the molten plastic flows. Must suit the customer's machine. |
| Dispersion | Whether the pigment spread evenly. "Specks" means it did not, and that causes rejected pipes and films. |
| Dispatch slip | The note that goes with a truck: which batch, how much, to whom. |
| Blast radius | If one lot was bad, every batch and every customer it reached. |
| Recipe adherence | Whether the operator charged what the recipe said, component by component. |
